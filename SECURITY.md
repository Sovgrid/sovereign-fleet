# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately through GitHub security advisories. Do not report security vulnerabilities through public GitHub issues.

## Scope

The following areas are in scope for security vulnerabilities:

- Sandbox escapes
- Token handling
- Path traversal

## Out of Scope

The following areas are out of scope for security vulnerabilities:

- Issues related to the configuration of the environment in which the software is run
- Issues related to the use of the software in a manner not intended by the authors

## Security Updates

Security updates will be released as soon as possible after a vulnerability is discovered and confirmed.
